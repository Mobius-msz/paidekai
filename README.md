# 撞不上 · 校园日程排班器

课表、二课、作业、阳光乐跑 —— 四套互不相通的系统，放在同一张桌子上算清楚。

**在线使用：** https://mobius-msz.github.io/zhuangbushang/

## 它解决什么

杭电学生的时间被四套系统切开：课表在钉钉，二课在素拓平台，作业在课程群，阳光乐跑在小程序。
每一套只回答「我这边有什么」，没有一套回答「它们会不会撞」。

这个网页把四类事件归一化成同一套模型，做四类冲突判定（时间重叠 / 转场来不及 / 当天过载 / 名额与时效），
再按六维打分排序推荐。**系统只排序和提醒，勾不勾、去不去，都是你自己决定。**

## 怎么用

1. 首次打开起个昵称、挑个头像（档案只存在你这台电脑的浏览器里）
2. 进「数据」页导入课表 —— 三条路任选：AI 整理、截图识别、手动填写
3. 填目标（二课学分 / 志愿时长 / 每周跑几天）
4. 在二课、志愿、跑操页按推荐分勾选
5. 每天看「日程」页：早八、空档、冲突，一屏看完
6. 活动结束后结算「去了 / 没去」

## 它不做什么

- 不自动报名（报名是不可逆的对外动作）
- 不爬任何系统（抓包属逆向，账号有封禁风险）
- 不碰你的账号密码

三个数据源我们都试过直连，都连不上 —— 具体原因写在网页的「关于」页里。

## 本地打开

纯前端，无依赖、无构建。双击 `index.html` 即可，也可以起个本地服务：

```bash
python -m http.server 8000
```

## 说明

演示用的活动池是模拟数据（28 条，按下一个自然周动态生成）。
二课/志愿/跑操的政策条款整理自《杭州电子科技大学学生手册》与 HDU Wiki，以学校最新通知为准。
